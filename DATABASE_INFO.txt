IMPORT OPTIONS
================================================================================

Option 1: Automatic (via setup.sh)
----------------------------------
The setup.sh script automatically detects and imports visante.sql

Command:
  ./setup.sh

What it does:
  ✓ Builds Docker containers
  ✓ Installs dependencies
  ✓ Generates app key
  ✓ Imports visante.sql (if exists)
  ✓ Sets up storage
  ✓ Fixes permissions


Option 2: Standalone Import
---------------------------
Use dedicated import script if containers are already running

Command:
  ./import-db.sh

What it does:
  ✓ Checks MySQL is running
  ✓ Creates backup of existing data
  ✓ Drops and recreates database
  ✓ Imports visante.sql
  ✓ Verifies import
  ✓ Shows statistics


Option 3: Manual Import
-----------------------
For advanced users who want full control

Commands:
  docker-compose up -d mysql
  sleep 30
  docker-compose exec -T mysql mysql -u visante -psecret visante < visante.sql

================================================================================
DATABASE STRUCTURE
================================================================================

The database contains tables for:

Users & Authentication:
  - users
  - roles
  - role_categories
  - personal_access_tokens (Sanctum)

Profiles:
  - patient_profiles
  - medecin_profiles
  - clinique_profiles
  - pharmacie_profiles
  - parapharmacie_profiles
  - centre_radiologie_profiles
  - labo_analyse_profiles

Features:
  - appointments (rdvs)
  - annonces
  - notifications
  - subscriptions

Character Set: utf8mb4_unicode_ci (supports French, Arabic, emojis)

================================================================================
TROUBLESHOOTING
================================================================================

Import fails?
  → Check MySQL is ready: docker-compose logs mysql
  → Wait 30 seconds after starting containers
  → Verify file exists: ls -lh visante.sql

Character encoding issues?
  → Database uses utf8mb4_unicode_ci
  → Check file encoding: file visante.sql

Need to re-import?
  → Run: ./import-db.sh (creates backup first)
